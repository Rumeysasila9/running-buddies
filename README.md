# RUNNING BUDDİES



## Description

Running Buddies is a Python-based running event application that allows runners to find running events and trainers, while trainers can create and manage their own running events.


## Features

### Main Menu
- Choosing between Trainer and Runner 
- Exiting the Application

### Trainer Menu
- View Your Profile
- Create New Event
- View Your Events
- Cancel Event
- Exit the Application

### Runner Menu
- View Your Profile
- View Events
- View Trainers
- Join an Event
- Cancel Participation
- Exit the Application



## Technologies

- Python
- Git
- GitHub



## How to Run 

1. Clone this repository:
```bash

git clone https://github.com/Rumeysasila9/running_buddies.git
```

2. Navigate to the project folder:
```bash

cd running_buddies
```

3. Run the application:
```bash

python running_buddies.py
```
